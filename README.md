📌 Task 1: Unit Converter Application
🔹 Description

The Unit Converter application helps users convert values from one unit to another.
It takes input from the user, allows selection of the conversion type, and displays the converted result.

🔹 Features

Centimeters ↔ Meters

Grams ↔ Kilograms

Simple and user-friendly interface

Accurate conversion logic

🔹 Technologies Used

Frontend: HTML, CSS

Backend Logic: Python

Platform: Google Colab (Web-based implementation)

📌 Task 2: To-Do List Application
🔹 Description

The To-Do List application allows users to manage their daily tasks, events, meetings, and important notes.
It includes user authentication to ensure data security and privacy.

🔹 Features

User Signup and Login

Secure Logout System

Add tasks, events, and notes

View saved tasks

Delete tasks permanently

User-specific data access

🔹 Technologies Used

Frontend: HTML, CSS

Backend: Python (Flask)

Database: SQLite

Platform: Google Colab (Web-based application)

📌 Task 3: Calculator Application
